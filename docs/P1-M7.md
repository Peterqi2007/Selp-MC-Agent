| 演练 | 断言 |
| --- | --- |
| 挂起任务超时 | 结果 `failed(timeout)`，slot 空，队列空 |
| 超时后的下一个任务 | 能正常执行，slot 释放 |
| 取消运行中任务 | 结果为 `cancelled`，slot 空 |
| 任务抛异常 | 结果为 `failed(throw)`，slot 空 |
| `preempt()` | 当前任务取消，队列清空，slot 空 |
