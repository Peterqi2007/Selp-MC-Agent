## 4. 残余风险（按影响排序）

1. **契约未接线**：`@` 闸门、语言/动作 registry 拆分、真实 harness 传输、代码生成、GUI——这些是
   P1 的核心行为，不是客户端测试能替代的；下一轮起按 M2→M3 顺序接线。
2. **持久化默认关闭**：A17/A29 未在真机验证；打开前不得宣称可恢复。
3. **阈值空置**：`/state` 周期、感知成本、聊天节奏、预算数值都未测量；500ms/3 次检索只是配置。
4. **模型行为未知**：所有提示词/persona/工具面只有静态断言，没有真实模型回执。
5. **两套规划循环**：默认 legacy 仍存在；切到 proposals 前必须完成 M6 的语言脑接管。
