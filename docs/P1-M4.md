## 2. 为什么先做这一层

A18–A20 要求的是"生成→检查→试运行→效果验证→晋升/回退"的闭环。闭环里**最危险也最可离线验证**
的是边界：命名空间不能覆盖内置、entry 不能逃出目录、未晋升版本不能分发、失败候选不能冒名、
回退必须精确。这些先固定下来，编码后端与真实受限执行才有可挂载的契约。
