### 1.3 2026-10-25 实时调用入口（本次新增）

此前生成/试运行/晋升只能经 HTTP `/code-skills/*` 触发，已晋升技能没有进入实时 Agent 的
可调用面（`catalog.js` 只提供元数据）。本次接上单一实时入口：

| 入口 | 行为 |
| --- | --- |
| `!code-skill list` | 列出当前 promoted 技能（未晋升/隔离版本不可见） |
| `!code-skill <name> [json]` | 后台任务运行**当前 promoted 版本**；未知/未晋升技能立即报错 |
| `code_skill` 任务类型（`TASK_BUILDERS`） | `mc_step`（命令串）与 `mc_plan` 步骤 `{"type":"code_skill","args":{"name":...}}` 都走同一派发；`PlanService.knownStepTypes` 自动包含 |
| 取消 | `!stop`/`!task stop` → `CodeSkillTask.cancel()` → `AbortController` → 沙箱杀子进程并清理 |
| 证据 | 每次运行写 `runtime/code-skill-runs/*-run.json`，任务事件保留 planId/stepId |

边界：只有 promoted 可达（`runPromoted` 不看候选）；试运行仍只在 HTTP 入口；命令本身不
触发生成，生成仍是操作员的显式 HTTP 调用。离线 `p1:m4:test 35/35`（含任务派发、未晋升拒绝、
取消中止与命令/任务注册断言）。

## 2. 设计边界

- **真实执行但仍是受限进程**：不是“信任模型”；静态扫描、permission model、worker 模块封锁、
  RPC 白名单、调用预算、超时、清理共同生效。
- **父进程不执行候选**：目录里的 entry 只被 sandboxWorker 读取；父进程只做生成/校验/证据/状态机。
- **不自动晋升**：生成/试运行成功只到 `trialled`；晋升是显式入口；失败/取消/超时不能晋升。
- **搜索是 Node 网络**：生成代码没有 direct network；查询先过滤坐标/IP/@玩家名；结果不拼进系统提示词。
- **子进程能力最高风险**：只允许 sandbox 目录内 Node 脚本，无 shell、10s、输出上限；真机验收前
  仍按高风险管理。
- **残余风险**：`vm` 不是安全边界（A19 探针确认逃逸可达 worker 进程，但模块全拒）；Node
  permission model 不覆盖网络，子进程改由 `subprocessGuard` 预载关闭（JS 层，不是内核防火墙）；
  `subprocess` 仍是高风险能力。详见沙箱规则文档，不宣称“恶意代码绝对隔离”。
