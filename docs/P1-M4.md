## 2. 设计边界

- **真实执行但仍是受限进程**：不是“信任模型”；静态扫描、permission model、worker 模块封锁、
  RPC 白名单、调用预算、超时、清理共同生效。
- **父进程不执行候选**：目录里的 entry 只被 sandboxWorker 读取；父进程只做生成/校验/证据/状态机。
- **不自动晋升**：生成/试运行成功只到 `trialled`；晋升是显式入口；失败/取消/超时不能晋升。
- **搜索是 Node 网络**：生成代码没有 direct network；查询先过滤坐标/IP/@玩家名；结果不拼进系统提示词。
- **子进程能力最高风险**：只允许 sandbox 目录内 Node 脚本，无 shell、10s、输出上限；真机验收前
  仍按高风险管理。
- **残余风险**：`vm` 不是安全边界；permission model 不提供 OS 级网络隔离；`subprocess` 可运行
  Node 脚本。详见沙箱规则文档，不在 A19 真机验收前宣称“恶意代码绝对隔离”。
