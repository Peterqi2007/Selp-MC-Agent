# 服务器皮肤方案（交给服主）

> **目标**：让**所有玩家**都能看到自定义皮肤，**玩家不需要装任何 mod**。
> **适用服务器**：Minecraft **1.20.1 + Forge**（你们服就是这个版本）。
> **改动方**：只需要服主改服务端，**客户端/玩家侧什么都不用做**。

---

## 一、先搞清楚：现在为什么全是默认皮肤

Minecraft 多人游戏里，"你看到别人的皮肤"这件事**不是客户端决定的，是服务端发过来的**。

正常流程是这样的：

```
玩家登录 → 服务端拿到这个账号的「皮肤属性」→ 下发给所有客户端 → 大家就看到了
```

**你们服的问题**：服务器是**离线模式**（就是进服要打 `/login 密码` 的那种，靠 AuthMe 插件验证），
服务端没有正版账号可以查，**所以它根本没有皮肤可以下发**。

结果就是：不管玩家自己电脑里放了什么皮肤文件，**别人看到的永远是默认的 Steve / Alex**。

> 玩家自己装「万用皮肤补丁 / CustomSkinLoader」这类**客户端** mod 只能**自己看到**皮肤，
> 对别人无效。这也是官方 FAQ 里明确写的：
> 「如果你想让别人也看见你的材质，请让他们也正确安装并配置皮肤 Mod。」

**解决办法**：给服务端装一个皮肤 mod，让服务端重新具备"下发皮肤"的能力。
装好之后，**任何玩家（原版客户端、不装任何 mod）进服都能看到彼此的皮肤**。

---

## 二、要装什么

| 项目 | 内容 |
| --- | --- |
| mod 名称 | **SkinRestorer**（注意是 `SkinRestorer`，**不是** `SkinsRestorer`） |
| 下载页 | <https://modrinth.com/mod/skinrestorer> （或 CurseForge 同名页面） |
| **要下载的文件** | **`skinrestorer-2.11.0+1.20-forge.jar`** |
| 直链 | <https://cdn.modrinth.com/data/ghrZDhGW/versions/WwS30jjd/skinrestorer-2.11.0%2B1.20-forge.jar> |
| 版本 | `2.11.0`，支持 MC `1.20` / `1.20.1`，加载器 `forge` |

> ⚠️ **别下错成 `SkinsRestorer`**（多一个字母 `s`）。
> `SkinsRestorer` 是 **Bukkit/Spigot/Paper 插件**，**纯 Forge 服务端装不了、会报错**。
> Forge 必须用 **`SkinRestorer`**（就是上面这个）。

> ⚠️ **如果你们服不是"纯 Forge"**，请先确认：你们启动服务端用的是哪种？
> - **纯 Forge**（`forge-1.20.1-47.x.x.jar` 启动）→ ✅ 直接用本文方案
> - **Arclight / Mohist / Magma 这类"能用插件的 Forge"** → ❌ SkinRestorer **和 Arclight ≤1.20.1 冲突**（作者明确写了）、
>   这种情况请改用 `SkinsRestorer` **插件**（放进 `plugins/` 而不是 `mods/`）
>
> 不确定的话，把服务端启动脚本的内容发出来确认一下即可。

## 三、服务端操作步骤（照着做）

### 第 1 步：装 mod

1. 打开服务端目录，找到 **`mods`** 文件夹
   （就是和 `server.properties`、`config`、`world` 同一层的那个 `mods`）
2. 把下载好的 **`skinrestorer-2.11.0+1.20-forge.jar`** 整个文件**复制进去**
   - 不要解压，`.jar` 直接放
   - 不要改名
3. **完全关闭服务端，再重新启动**
   （只 reload 不行；装 mod 必须重启）

### 第 2 步：确认 mod 加载成功

启动日志里搜 `skinrestorer`，应该能看到它被加载。
同时服务端目录下会**新出现**这个文件夹：

```
服务端目录/config/skinrestorer/config.json
```

**看到这个文件出现，就说明 mod 装成功了。**
（如果没出现，说明 mod 没装对：检查是不是放进了 `plugins`、是不是放错目录、是不是下成了 SkinsRestorer）

### 第 3 步：什么都不用配（默认就是对的）

打开 `config/skinrestorer/config.json`，确认这两项是下面这样（**默认值就是对的，一般不用改**）：

```jsonc
{
  "join": {
    "autoFetch": {
      "enabled": true,            // 默认 true。离线服专用：进服时自动按游戏名去找皮肤
      "providers": ["mojang"]     // 先去 Mojang 找。想再加个备选可写成 ["mojang", "ely.by"]
    },
    "refreshSkin": true           // 默认 true。每次进服重新拉一次
  }
}
```

改成 `["mojang", "ely.by"]` 的好处：Mojang 上找不到的皮肤，会再去 [Ely.by](https://ely.by/) 找一次。

> 改完配置保存即可，不需要重启（也可以用 `/skin config reload` 让它立刻生效）。

### 第 4 步：之后玩家进服会自动有皮肤

`join.autoFetch.enabled` 默认是 `true`，含义是：
**离线服里，玩家第一次进服时，服务端会拿他的游戏名去 Mojang 找一个同名的正版账号，把人家的皮肤拿过来下发。**

所以：**只要玩家的游戏名和某个"有皮肤的正版账号"同名，他进服就自动有皮肤了，你什么都不用敲。**

> 注意：这只在"还没保存过皮肤"的时候生效（每个玩家第一次进服那次）。

### 第 5 步（可选）：给某个玩家指定一张自己的图

想用**自己的**皮肤图（不是某个正版账号的），在**服务端控制台**或游戏里（OP）敲：

```
/skin set web classic "https://图片的公开直链/xxx.png"
```

- 敲这条命令的玩家 = 被改皮肤的人（玩家自己敲就是改自己）
- 服主可以代替别人改，在**最后加上玩家名**：

```
/skin set web classic "https://图片的公开直链/xxx.png" 玩家名
```

- `classic` = 经典（Steve）模型；如果是**纤细（Alex）模型**，把 `classic` 换成 `slim`
- 图片要求：**必须放在公网能访问的地址**（图床、你自己的网站都行），
  **服务器本地硬盘上的文件不行**——服务端要自己去把这张图下载下来
- 这条命令底层会用 [mineskin.org](https://mineskin.org/) 生成皮肤，所以**服务器必须能访问外网**

其他可用命令：

| 命令 | 作用 |
| --- | --- |
| `/skin set mojang <正版用户名>` | 用某个正版账号的皮肤 |
| `/skin set ely.by <Ely.by用户名>` | 用 Ely.by 站的皮肤 |
| `/skin set web (classic\|slim) "<图片直链>"` | 用一张自己的图 |
| `/skin refresh` | 重新拉一次当前皮肤 |
| `/skin clear` | 清掉皮肤（回到默认） |
| `/skin config reload` | 配置改完即时生效，不用重启 |

### 第 6 步（可选）：限制谁能改皮肤

默认设置是：**任何人都能改自己的皮肤**，但**不能改别人的**（改别人需要权限等级 2 = OP）。

如果不想让玩家自己乱改，打开 `config/skinrestorer/config.json`，把：

```jsonc
"command": {
  "permissionLevel": 0     // 改成 2 → 只有 OP 能改皮肤，普通玩家不能
}
```

改完敲 `/skin config reload`，**立刻生效，不用重启**。

## 四、怎么验证成功了（重要）

**验证方法：让两个玩家同时在线，互相看对方。**

| 检查项 | 正确结果 | 如果不对 |
| --- | --- | --- |
| 服务端 `config/skinrestorer/` 目录 | 存在 | mod 没装对 → 回到第 1 步 |
| 服务端日志 | 有 skinrestorer 加载记录 | 同上 |
| 玩家 A 看玩家 B | **能看到 B 的皮肤** | 见下面「常见问题」 |
| 玩家自己看自己 | 正常 | 需要重新进服一次 |

**注意**：改完皮肤或刚装好 mod 后，**玩家要重新进一次服务器**才会刷新，
客户端还可能缓存一阵子——多等几分钟或退出重进。

## 五、常见问题速查

**Q1：装完没反应，还是默认皮肤**
- 服务端**重启**了吗？（不是 reload）
- `.jar` 是放进 `mods` 了吗？（不是 `plugins`）
- 是不是下成了 `SkinsRestorer`（Bukkit 插件）？必须用 `SkinRestorer`
- 玩家**重新进服**了吗？

**Q2：某个玩家名字上有个正版账号，但显示的是"别人的皮肤"**

这是**正常现象**：离线服里服务端只能"按名字找"，谁的名字和正版账号一样，就会拿到那个账号的皮肤。
不想要的话，就用第 5 步给他**单独指定一张图**（`/skin set web ...`），手动指定的会覆盖自动获取的。

**Q3：`/skin set web` 报错**
- 图片地址**必须是公开可访问的直链**（浏览器直接打开能看到图），本地文件路径不行
- 服务器必须**能上外网**（要访问 mineskin.org 和图床）
- 图片格式：PNG，尺寸必须是 Minecraft 皮肤标准尺寸（64×64 或 64×32）

**Q4：玩家抱怨"我的皮肤在别的服能看到，在你们服看不到"**

这是因为别的服要么是正版服（服务端能拿到皮肤），要么装了类似 mod。
装好 SkinRestorer 后这个问题就解决了。

**Q5：装完服务端起不来 / 报错**

先确认服务端类型（见第二节的警告）。如果是 Arclight ≤1.20.1，SkinRestorer 不兼容，
改用 `SkinsRestorer` 插件版。其他情况把**服务端启动日志的报错部分**发出来看。

---

## 六、给服主的一句话总结

> 下载 **`skinrestorer-2.11.0+1.20-forge.jar`**（注意不是 SkinsRestorer），
> 丢进服务端 **`mods`** 文件夹，**重启服务端**。
> 看到 `config/skinrestorer/` 目录出现就算成功，**默认配置不用改**——
> 玩家的游戏名只要和某个有皮肤的正版账号同名，进服就自动有皮肤。
> 想用自己的图，敲：`/skin set web classic "图片公网直链" 玩家名`。
> **其他玩家什么都不用装。**

供服主核对，避免重复排查：

| 是否配了 Yggdrasil 外置登录 | 否（服务端用 AuthMe 离线登录） |

> **关于"外置登录"这条备选路线的说明**（服主可能听说过）：
> 给服务端配 Yggdrasil 外置登录（authlib-injector + 皮肤站）也能解决皮肤问题，
> 但那要求**所有玩家改用外置登录方式进服**（要换登录方式、可能要重装客户端配置），
> 对公共服来说代价太大、容易劝退玩家。**所以本文推荐装 mod 这条更简单的路。**
