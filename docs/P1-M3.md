## 2. 设计边界（为什么默认关闭）

- 恢复的是**问题与计划**，不是动作：在途任务、身体所有者、LLM 回合都不进入快照，重启后绝不重放。
- 恢复出来的提案是 `awaiting`，**不是同意**；玩家回答后才执行，过期问题在下次提案时被清理。
- 默认 `enabled=false`：没有真机验收（A17/A29）前不改变现网写盘行为；打开后路径为
  `runtime/p1-state.json`（gitignored）。
