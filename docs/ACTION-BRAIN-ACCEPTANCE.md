### 1.1 通过与阻断规则

每项采用 NOT_RUN / PASS / FAIL / BLOCKED / NOT_APPLICABLE。PASS 必须具备测试输入、实际结果和可追溯证据；依赖无法启动为 BLOCKED，不能记为通过。NOT_APPLICABLE 必须说明产品明确不提供的能力及其拒绝路径，不能跳过首选 provider、停止、恢复或 Windows 交付。

“失败阻断”表示该项失败后不得关闭相应阶段；只允许继续无关的只读研究、夹具开发和隔离测试。身体互斥、停止、权限、恢复与插件越权属于全局硬门：失败后不得继续非隔离真机动作或发布。

任何必需项未执行、证据缺失或失败，均不得宣布迁移完成。门槛修改必须先修订计划、说明理由、保留旧结果，不得测完后改门槛掩盖失败。

## 4. B2：游戏控制、停止与恢复

出口：新 runtime 持有可验证生命周期；模型/工具/插件组合不能绕过单身体 owner 与停止 fence。

### 4.1 停止顺序

停止/接管的首个动作必须是**本地执行资格失效**：原子设置 stop hold、递增 epoch 或撤销 lease。副作用 dispatch 在发身体命令前再次检查资格；旧 run 不能因模型回执重获资格。

期望顺序：stop received → fence installed → releaseAll / body interrupt / plan-task cancel → abort model and descendants → settle。除 fence 必须最先外，释放、interrupt、取消可按可证明安全的方式并发；不得等模型网络取消才释放输入。不能声称撤销 stop 前已发生的物理效果。

若 releaseAll、interrupt、取消或确认超时/失败，必须保持 stop hold 与写通道关闭，并在状态及 UI 显示“停止未确认”和具体失败；不能显示已停稳、自动恢复或重新发放身体租约。只有重新取得可靠停止证据、刷新实际状态并获得显式恢复授权，才可解除 fence。

## 7. B5：性能、Windows 分发与升级回滚

出口：用可重复数据比较 DSH；干净 Windows 可安装使用；升级失败可恢复。不能因支持 streaming 或主观感受宣布更快。

### 7.1 性能场景、时间点与统计

冻结同一游戏/Mod、场景、实际模型 ID、provider 路由、thinking/采样、工具语义、截图大小、上下文长度。尽量冻结 system prompt；无法相同时保存 hash/差异，标为**产品配置比较**，不能全部归因框架。DSH 仅在对照测试机出现，不是新产品依赖。

至少六场景：①简单只读观察；②已有技能短任务；③多步计划+一次失败；④阅读+编码试运行；⑤长上下文压缩；⑥慢规划中突发威胁+两个只读子代理。每配置每场景至少50次，交错/随机顺序，冷启动与热运行分开。失败、超时、取消保留且单列，不从成功率分母删除。样本不足只给描述，不下 p95 稳定结论。

| 时间点 | 定义 |
| --- | --- |
| t0 | 产品收到玩家请求/世界事件，使用单调时钟 |
| t1 | 请求被调度，所需状态刷新完成 |
| t2 | 发首个模型请求 |
| t3 | 首可观测输出；首 token/首完整工具参数分别记 |
| t4 | broker 受理首合法工具；另记等执行权时间 |
| t5 | Mod 接首身体命令；只读任务为 null |
| t6 | 真实世界出现可验证效果，不能以 HTTP 200 代替 |
| t7 | 任务证据结算与 agent_settled，分别记 |
| ts/tf/tr/ta | stop 到达 / fence 生效 / Mod 输入归零且动作中断 / SDK及后代 settled |

统计 t1-t0 感知/调度、t2-t1 上下文/宿主准备、t3-t2 provider 首响应、t4-t3 参数完成/派发、t5-t4 执行权/传输、t6-t5 游戏执行，以及端到端首动作/完成。Node 内用单调时钟；跨进程不能直接减不对齐时钟，优先由协调器记录请求/回执并保留 Mod 本地耗时。各项报 n、成功率、p50/p95、最大值、超时率；分位采用排序后 nearest-rank ceil(p*n)，公开原始样本与算法。

以下是**项目提出的初始实验目标，尚无实测支持**，不是已验证能力或对全部客户硬件的承诺：

- 健康本机夹具 tf-ts p95≤50ms、tr-ts p95≤500ms；故障仍先 fence，不能等 provider。未达时报告瓶颈并修订目标，不能绕安全门。
- 热运行纯调度/派发开销 p95≤100ms；慢模型、compaction、worker 期间，600ms 反射循环的额外调度迟滞 p95≤100ms。周期与迟滞分报，不把600ms周期写成100ms反应。
- 同模型/场景/可比配置下，首身体动作和任务完成 p95 不劣于 DSH、成功率不下降。宣称更快需说明指标、分布和不确定性，不能只给总平均或一次成功。
- 没有模型推理加速承诺。可得出控制/交付收益成立、速度提升未证实的结论。
