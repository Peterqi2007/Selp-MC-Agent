## 1. 已交付（离线）

| 契约 | 位置 | 说明 |
| --- | --- | --- |
| **未读消息去重** | `src/chat/conversation.js` | 同一消息 id（或发送者+文本）在 `dedupeMs` 内只处理一次；窗口过后视为新消息 |
| **过时回复拒绝** | 同上 | `beginRequest()` 标记当前请求；旧请求的候选回复返回 `stale-request`，两个交错请求不会都开口 |

| **限速与重复回复** | 同上 | `minGapMs` 内不连发；同一回复文本在窗口内拒绝；超长文本截断到 `maxChars` 并标记 `truncated` |
| **无名称关键词过滤** | 同上 | 遵循 P1：不新增按名字的语义过滤；触发/前缀仍由监听器负责 |
| **持久化** | `src/core/sessionState.js` | 已见消息、最近回复、最后发送时间、当前请求随会话恢复（A17） |
| **按需接线** | `src/chat/reply.js` + `src/llm/index.js` | LLM 回复可选择走守卫（`options.conversation`）；`chat.conversationGuard` **默认 false**，命令 ack/任务播报/强制播报不经过守卫——默认行为未变 |
| **审计/测试** | `plan:audit --stage p1` / `p1:contract:test` | p1 **59/59**；契约 **73/73**（去重/过期/自回声/限速/重复/截断/恢复/opt-in 接线） |
